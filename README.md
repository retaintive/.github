# Retaintive GitHub defaults

本 public repository 保存 Retaintive organization-wide、无敏感信息的 GitHub contribution defaults。

## Current defaults

- `.github/pull_request_template.md`：当 Retaintive repository 没有自己的 PR template 时，由 GitHub 自动提供默认 PR body。

Repository-specific template 会覆盖这里的 default。Internal automation、credentials、private runbooks 和 product code 不应放在本 repository。
